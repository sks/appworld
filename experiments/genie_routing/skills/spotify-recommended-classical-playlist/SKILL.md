# New playlist of this year’s recommended classical songs

Create a playlist called “Spotify Recommended Songs” and fill it with classical songs Spotify has recommended that were released in the simulated current year.

Sign into Spotify. Browse recommendations, keep only classical tracks whose release year matches this year, create the named playlist if it does not already exist as required, and add those songs. Do not add non-classical or older releases.

Finish as an action-only success (no answer string).

## Tools you will need

Spotify login, recommendations, create playlist, add songs; supervisor complete_task.
