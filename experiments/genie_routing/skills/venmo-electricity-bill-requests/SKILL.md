# Split last month’s electricity bill on Venmo

You paid last month’s electricity bill. The cost should be split equally among you and your roommates. Send each roommate a Venmo payment request with description “For electricity bill.” The receipt lives in the File System.

Sign into the File System and Venmo. Find the electricity bill receipt, read the total, and compute each roommate’s equal share (your own share stays with you — only request from roommates). Identify roommates from profile/relationships. Create one payment request per roommate for that share amount with the exact description note.

Finish as an action-only success (no answer string).

File System read of the bill; Venmo login and create payment request; supervisor profile/passwords, complete_task.
