# Clear pre-2021 songs from library and playlists

Anything released before 2021 should leave both your song library and your playlists.

Sign into Spotify. Scan the song library and every playlist. For each song with a release year before 2021, remove it from the library and from any playlist that contains it. Leave 2021-and-later songs alone. Finish as an action-only success (no answer string).

## Tools you will need

Spotify login, library/playlist/song inspection, remove-from-library and remove-from-playlist style mutates; supervisor complete_task.
