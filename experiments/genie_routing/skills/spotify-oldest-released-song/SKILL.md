# Oldest release in the libraries

Ask: among songs you own across the song library, album library, and playlists, which title has the earliest release date?

Sign into Spotify. Scan song, album, and playlist libraries thoroughly. For each song, note release date and title. Keep the oldest release you find. When finished scanning, complete the task with that song’s **exact title string**.

Do not delete or move songs while answering.

## Tools you will need

Spotify login and library/playlist/song reads; supervisor complete_task with the title as the answer.
