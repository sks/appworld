# This year’s electricity bill total

This is a question. Add up electricity bill amounts for the simulated year from files under `~/bills/` in the File System.

Sign into the File System. List and open bill files for this year (ignore other years if present). Sum the electricity costs you find. Complete the task with that **total as the answer string** — not null.

## Tools you will need

File System login, list/show/read files under bills; supervisor complete_task with the total as the answer.
