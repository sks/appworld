# Refund Robert’s accidental payment

You accidentally sent Robert a Venmo payment request; he approved it, so the money moved. You need to send that same amount back.

Sign into Venmo through the password vault. Find the latest approved payment request you sent to Robert — look at sent payment requests and related transaction history until you identify the right person and amount. Then create a Venmo transaction that pays Robert back that amount. Use Venmo’s real payment-creation path, not invented “send payment” names.

If an auth error appears mid-way, re-login once from the vault and retry. Do not ask which recovery option to pick. Finish as an action-only success (no answer string).

## Tools you will need

Venmo login, show sent payment requests / transactions, create transaction; supervisor profile, passwords, complete_task.
