# Like everything already in the queue

Like every song that has played so far in the Spotify player queue, including the song that is playing now.

Sign into Spotify. Inspect the current queue / playback state, identify songs already played plus the current track, and like each of them. Do not clear or rebuild the queue; do not like unrelated library songs.

Finish as an action-only success (no answer string).

## Tools you will need

Spotify login, show queue / current playback, like song; supervisor complete_task.
